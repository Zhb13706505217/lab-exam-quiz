# 上岗证刷题 · 实验室基础知识（第1章）

生态环境监测技术人员持证上岗考核理论试题集 —— 第1章 基础知识 刷题工具。

**在线使用**：https://zhb13706505217.github.io/lab-exam-quiz/

## 特点

- 1510 题：填空题 403 / 单选题 452 / 多选题 183 / 判断题 472（已剔除简答题与计算题）
- 按章节单独练，或全部混合练；每轮顺序随机
- 本轮题量可选 50 / 100 / 200 / 全部
- 答题过程可随时退出：继续答题 / 重新开始本轮 / 保存并退出稍后继续
- 错题本按错误次数从多到少排序，支持错题专项重练
- 每轮正确率趋势、各章节掌握度统计
- 填空题前两轮为熟悉模式（答案直接显示在题干里），之后逐空作答、自动判分、可自评判对
- 完全离线运行，数据只存在本机；支持导出 / 导入备份
- 支持深色模式、字号调节

## 在 iPhone 上安装

1. 用 **Safari** 打开 https://zhb13706505217.github.io/lab-exam-quiz/
2. 点 分享 → **添加到主屏幕**
3. 桌面出现图标，点开即全屏运行，断网也能刷题

## 本地运行

双击 `启动本地服务器.bat`，或直接双击 `index.html` 用浏览器打开。

## 文件说明

```
index.html            应用入口
app.js                应用逻辑（答题、判分、统计、错题本）
styles.css            界面样式
bank.js               题库数据（1510 题，内嵌离线可用）
manifest.webmanifest  PWA 清单
sw.js                 离线缓存（Service Worker）
icons/                应用图标
使用说明.md            使用手册
启动本地服务器.bat      电脑本地预览
```
